# Hi there, I'm Giorgi Kapanadze 👋

🛰️ **See what others can't** · GIS & remote sensing · Chiatura, Georgia 🇬🇪

I'm a GIS person who loves open-source software and the situations where GIS meets system development: databases, plugins, small apps, scripts that glue things together. Most of my work is built around that, and most of it lives in community organizations rather than on this profile.

## 🌍 Where my work lives

- **[GIS-GEORGIA](https://github.com/GIS-GEORGIA)** is the community behind [qgis.ge](https://qgis.ge), an independent, volunteer-run group promoting open-source GIS in Georgia.
  - **[plugins.qgis.ge](https://plugins.qgis.ge)** is a QGIS plugin repository for Georgian spatial data, with English and Georgian interfaces. [Source](https://github.com/GIS-GEORGIA/qgis-plugins-repo)
  - **PostGIS Manager** is a bilingual QGIS plugin for managing PostGIS data (QC rules, batch tracking).
  - Applications, scripts and tools around QGIS, PostGIS, GeoServer and INSPIRE-style data models.
- **Georgian Cartographers Association** is where I take part in joint projects, websites and applications.

## 🤝 Contributing to open source
